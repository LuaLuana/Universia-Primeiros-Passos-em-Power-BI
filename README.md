Repositório com os projetos e exercícios que desenvolvi no bootcamp **Universia – Primeiros Passos em Power BI**, oferecido pela **DIO (Digital Innovation One)**.

O bootcamp tem como objetivo ensinar os primeiros passos na **análise de dados**: como importar, tratar, organizar e transformar dados em relatórios e dashboards que ajudam a tomar decisões.

---

## 🎯 O que este repositório mostra

- Importação de dados de diferentes fontes (planilhas Excel e banco de dados)
- Tratamento e limpeza de dados com o **Power Query**
- Organização dos dados para análise (tipos de dados, junções, colunas calculadas)
- Criação de **relatórios e dashboards** no Power BI Desktop
- Documentação do projeto no GitHub

---

## 🧰 Ferramentas utilizadas

| Ferramenta | Para que usei |

## ▶️ Como abrir o relatório

1. Baixe o arquivo `.pbix` (na página do arquivo no GitHub, clique em **Download raw file**).
2. Abra com o **Power BI Desktop**, que é gratuito e disponível para Windows.
3. Se o Power BI pedir para atualizar as fontes de dados, aponte para o arquivo `Financial Sample (1).xlsx` da mesma pasta.
